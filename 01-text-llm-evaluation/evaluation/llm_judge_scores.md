**評分維度**：
- 理 = 理解力（Q1，1-5）
- 具 = 具體性（Q2，1-5）
- 風 = 風險揭露（Q2，1-5）
- 邏 = 邏輯連貫性（Q3，1-5）
- 時 = 時間污染指數（Q4+全程，1-5；分數越高代表越乾淨）
