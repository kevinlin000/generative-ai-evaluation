# 生成式 AI 評估

這個 repo 收錄三份生成式 AI 評估作品,分別處理文字模型、圖像模型與影片生成流程。三份作品都沿用同一個原則:固定輸入、控制變因、比較輸出,再把差異整理清楚。對我來說,這不只是模型測試,也是把問題拆清楚、建立評估方式、整理證據與做取捨的實作紀錄。

中文 / [English](./README.en.md)


## 這裡有什麼

- **文字模型評估**:把五個 LLM 放到三個歷史崩盤前夕,檢查它們給投資建議時到底是判斷力不足,還是只是語氣很像懂。
- **圖像模型評估**:不直接點名人物,只給語意線索,觀察模型會先聯想到誰,以及安全邊界怎麼介入。
- **文字到影片流程**:從腳本、角色到動畫一路生成,做出一支水墨武俠短片,並記錄每一階段的模型取捨。


## 這份作品怎麼看

- 三份作品跨了三種模態,但方法一致,不是三個互不相干的小作業。
- 重點不是「模型做得出來嗎」,而是「它為什麼這樣做,錯在哪裡,哪裡可靠,哪裡不可靠」。
- 每份報告都有明確問題、可追溯素材與具體觀察,不是只放成品圖或生成結果。
- 如果把它當成求職作品來看,比較能反映的是我怎麼定義問題、設計比較方式、整理結果,以及在工具與限制之間做判斷。


## 報告一 文字模型在崩盤前夕的投資建議可信度

**核心問題**

在市場最容易誤判的時候,LLM 給出的投資建議到底能不能信。

**做法**

對五個模型(ChatGPT 5.3、Claude Opus 4.7、Gemini 3.1 Pro、DeepSeek R1、TAIDE)在三個歷史時點(2008 雷曼、2022 台股高點、2024 AI 熱潮頂點)施以同一條五階段提示詞鏈。三個情境只替換時間點與市場資料,其餘條件固定。共 75 段對話,全部保留逐字稿。

**主要發現**

- 2008 與 2022 前夕各有 4/5 模型系統性低估下行風險。
- 偏差最大者是 TAIDE 在 2022 情境,與真實半年報酬相差 24.9 個百分點。
- 用 Claude 當評審時,Claude 對自己答案有明顯高估,顯示單一模型自評不可靠。
- TAIDE 自然語言表面流暢,但在三分之二的情境未通過 JSON schema 驗證,輸出無法直接被後端解析。

**評分方式**

6 個維度,人工與 LLM-as-judge 雙軌評分,評分者間一致性 Pearson r = 0.801。

**看這裡**

`01-text-llm-evaluation/` 內含對話逐字稿、評分矩陣、真實報酬對照、截圖、簡報與講稿。


## 報告二 圖像模型對暗示型提示的語意聯想

**核心問題**

當提示詞刻意不點名,模型究竟會先抓住哪些語意線索,又會把它們聯想到哪裡。

**做法**

設計 18 組暗示型提示,以特徵、場景與年代描述取代直接指名,對 GPT 與 Gemini 施以相同輸入,再把輸出分成三類:文化共識、語意分歧、安全邊界。

**主要發現**

- 有些提示兩個模型會穩定收斂到同一個指涉,顯示存在強烈的文化共識。
- 有些提示會讓兩個模型走向完全不同的人物或年代,暴露語意權重的差異。
- 安全規則不是附屬限制,而是直接參與了最終輸出。

**這份報告關心的是什麼**

這份報告不是在比「誰畫得像」,而是在看圖像生成如何同時受到訓練記憶、語境判讀與平台規則牽動。

**看這裡**

## 報告三 文字到影片的端到端生成流程

**核心目標**

把腳本、角色與動畫三個階段串起來,做出一支約兩分鐘的水墨武俠短片《松風武林·物件導向之卷》,用敘事講解物件導向的封裝、繼承、多型。

**流程設計**

- 腳本:同一份世界觀輸入,比較 ChatGPT 與 Gemini 的結構與趣味性,最後融合兩者版本。
- 角色:比較 GPT image 2.0 與 Gemini Nano Banana,依第三幕多角色同框需求做取捨。
- 影片:原先規劃用 Sora,後因 Sora 於 2026/04 停止服務,改接 Google Flow / Veo,上游素材不重做。

**主要發現**

- 真正困難的不是單張圖生成,而是跨鏡頭角色一致性。
- 多角色同框時,任務適配度比單張美感更重要。
- 影片流程一旦分階段拆清楚,即使中途更換模型,也不需要整個專案重來。

**技術心得**

- 利用 Flow 的「角色」建檔功能綁定固定參考圖,壓低外觀漂移。
- 固定鏡頭、主體置中、重複強調關鍵細節,比堆更多形容詞更有效。
- 未明確指定之處,模型會自行補完,而且通常不是你要的。

完整素材與報告: `03-video-oop-pipeline/`


## 限制

三份作品都是小規模案例研究,不是統計顯著的實證研究。樣本量有限,提示詞由作者設計,生成結果也有隨機性。報告一的 LLM 評審本身帶有偏誤,雖以人工評分平衡,但無法完全消除。2024 情境的真實值也只累積數個月,長期可靠度仍待驗證。


## 使用工具

文字:ChatGPT、Claude、Gemini、DeepSeek、TAIDE,皆透過網頁介面而非 API,以保留含系統提示與檢索增強在內的真實使用者端行為。

圖像:GPT image 2.0、Gemini(Nano Banana)。

影片:Google Flow(Veo),後製使用剪映。

評分與分析:Python。
